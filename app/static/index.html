About processing speed

RTFx = audio duration ÷ processing time. Above 1× is faster than real time. RTF is the inverse; below 1 is faster. Processing time includes preparation, model requests, and exports. Totals use completed files still in this workspace. Queue waiting and model startup are excluded. Active-file speeds use completed segments and are provisional.

How these numbers work

RTFx is audio duration divided by processing time. RTF is the inverse. Totals are weighted using summed times for completed files still in this workspace. Processing includes media preparation, model requests and exports. Upload time, queue waiting and model startup are excluded.
